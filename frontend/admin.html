Password Recovery:
The admin password is stored only as a bcrypt hash in the server environment variable ADMIN_PASSWORD_HASH. To reset it, generate a new hash with python scripts/generate_admin_hash.py and update ADMIN_PASSWORD_HASH in your .env file, then restart the service.
